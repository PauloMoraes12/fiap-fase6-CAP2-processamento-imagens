# Processamento e Análise de Imagens com Python

## Sobre o projeto

Repositório de estudos e aplicações práticas desenvolvido durante a Fase 6 do curso de Data Science da FIAP.

O objetivo é compreender os fundamentos do processamento e da análise de imagens utilizando Python, desde a representação numérica de pixels até técnicas de manipulação e extração de informações.

## Objetivos de aprendizagem

- Compreender a representação de imagens por matrizes.
- Trabalhar com pixels e canais RGB.
- Utilizar NumPy para manipular dados de imagens.
- Explorar bibliotecas de processamento de imagens.
- Desenvolver aplicações práticas de análise de imagens.
- Estudar reconhecimento óptico de caracteres (OCR).

## Tecnologias

- Python
- NumPy
- Visual Studio Code
- Git e GitHub

*Outras bibliotecas serão adicionadas conforme o desenvolvimento do projeto.*

## Organização do repositório

A estrutura de pastas será construída progressivamente, separando códigos, imagens de exemplo, documentação e testes.
